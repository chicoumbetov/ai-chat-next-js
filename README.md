# AI ChatBot

Краткое описание проекта
Интеллектуальный ассистент с веб интерфейсом для обмена сообщениями с языковой моделью. Проект решает задачу быстрой и безопасной коммуникации с искусственным интеллектом через изолированный бэкенд шлюз.

Технологический стек и обоснование
Фронтенд реализован на Next.js с TypeScript и Tailwind CSS. Выбор обусловлен быстрой сборкой, встроенной поддержкой маршрутизации и удобством деплоя на Vercel.
Бэкенд написан на Python FastAPI. Фреймворк выбран за высокую производительность, автоматическую генерацию документации Swagger и идеальную совместимость с экосистемой искусственного интеллекта.
Интеграция с LLM выполнена через API Groq с использованием быстрой модели Llama 3, что обеспечивает мгновенный ответ и минимальную задержку.

Архитектура
Применение получила упрощенная модульная архитектура. Логика разделена на изолированные слои. Маршрутизаторы принимают запросы, сервисы инкапсулируют бизнес логику взаимодействия с моделью, а схемы валидируют данные на входе и выходе.

Инструкции по установке и запуску
Клонируйте репозиторий на локальную машину.
Перейдите в папку бэкенда, создайте виртуальное окружение, установите зависимости из файла requirements.txt и запустите сервер командой uvicorn app.main:app reload.
Перейдите в папку фронтенда, установите зависимости командой npm install и запустите клиент командой npm run dev.
Создайте файл переменных окружения с ключом доступа к API модели.

Процесс проектирования и разработки
Разработка велась итеративно. На первом этапе создан базовый интерфейс чата. На втором этапе подключен бэкенд на FastAPI и настроен защищенный вызов внешней языковой модели. На завершающем этапе добавлены переключение тем оформления и визуальные скелетоны загрузки.

Компромиссы и принятые решения
Хранение истории сообщений реализовано в оперативной памяти бэкенда для упрощения архитектуры в рамках тестового задания без подключения тяжелых баз данных. Стриминг ответов временно упрощен до пакетной передачи ради надежности соединения.

Известные ошибки и проблемы
При высокой нагрузке на внешнее API возможны задержки ответа. Отсутствует персистентное сохранение истории диалогов после перезагрузки сервера.
